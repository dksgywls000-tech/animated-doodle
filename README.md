# animated-doodle
## 석우의 반종인터벌 (`banjong-interval.html`)

석우형이 보내는 인터벌 메모(날짜·장소·세트·해시태그)를 그대로 붙여넣으면 단톡/인스타용 포스터 PNG를 만들어 주는 단일 HTML 도구.

- 메모 자동 분석: 날짜/요일, 집합 시간(`12:00`, `오후 7시 반`), 장소, `[ ]` 제목, 세트 줄(`1 set`, `1-7 set`, `0세트 3km 워밍업`), 해시태그
- 석우형 산수 검수: 요일, 총 볼륨, 세트 수, `페이스 × 거리 = 초` 오타 검사 + 원클릭 정정
- 포스터: 피드 4:5 / 스토리 9:16, 타탄 트랙 · 나이트 · 배번표 테마, 맛 판독(순한~지옥맛)에 따라 바뀌는 그림 석우형, 말풍선 대사, 해시태그 스티커, 인터벌 그래프, 종료 예상 시각, 치킨 환산 칼로리
- 저장: PNG 저장 / 공유 / 단톡 공지문 복사 (휴대폰은 포스터 길게 눌러 저장)

브라우저에서 파일을 열기만 하면 됩니다. 빌드나 서버가 필요 없습니다.
