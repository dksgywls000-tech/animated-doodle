## 5. TTS 대본 + 씬 구성

- `tts` 열은 읽기용이라 숫자를 한글로 풀어 썼음. 화면 자막은 `자막` 열을 사용.
- 각 씬 길이는 해당 TTS 길이 + 0.25초 여유로 맞춤.

| # | 씬 | tts | 자막 | 모션그래픽 아이디어 |
|---|---|---|---|---|
| 1 | HOOK | 하이록스처럼 뛰면, 어반웨이브에선 노렙입니다. | 하이록스처럼 뛰면 **노렙** | 네온 터널을 카메라가 빠르게 통과 → "DON'T RUN IT LIKE HYROX." 슬램 인 → 빨간 NO REP 도장 |
| 2 | 대조 | 룰북 두 개 펼쳐놓고, 다른 것만 골라봤어요. | 룰북 2개, **다른 것만** | HYROX / URBANWAVE 문서 두 장이 좌우에서 들어와 겹치고, 다른 줄만 그린 형광펜 |
| 3 | 숫자 | 러닝은 팔백 미터씩 여덟 번. 월볼은 백 개가 아니라, 백이십 개. | 월볼 ~~100~~ → **120** | 카운터 100이 취소선 → 120으로 롤링. 6.4KM, 11종목 숫자 팝 |
| 4 | 웨이브존 | 첫 바퀴 뛰고 나면, 다섯 종목을 쉬지 않고 이어서 해요. | 첫 800m 후 **러닝 없이 5종목** | 스테이션 박스 6칸(RUN→ROW→SNATCH→LUNGE→BOX→BURPEE)이 차례로 점등, 사이 화살표에 "NO RUN" |

| 8 | 즉시 페널티 | 혼자 먼저 나가면, 경고 없이 바로 이 분. | 혼자 나가면 **+2:00** | OUT 아치를 한 명만 통과 → 타이머 +2:00 슬램 + 화면 셰이크 |

## 6. 사실관계 (영상에 쓰는 수치는 이 표만 사용)

출처: `assets/rulebooks/URBANWAVE_2026_RULEBOOK_V4.pdf`

| 항목 | 어반웨이브 | 하이록스 더블 |
|---|---|---|
| 러닝 | 800m × 8 = 6.4km, 둘이 6m 안에서 같이 | 1km × 8 = 8km |
| 종목 수 | 11 (웨이브존 5 + 레이스존 6) | 8 |
| 웨이브존 | Run 800 → Row 1,000m → DB 스내치 40 → DB 워킹런지 40m → 박스 점프 오버 40 → 버피 오버 더 웨이브 40 (02–06 사이 러닝 없음) | — |
| 레이스존 | Run → 에어바이크 2,000m → Run → 썰매 푸시 75m → Run → 썰매 풀 75m → Run → 스키 1,000m → Run → 파머스 200m → Run → 월볼 120 → Run → 피니시 | 썰매 50m(4랩), 월볼 100 |
| 썰매 | 12.5m × 6랩 = 75m | 12.5m × 4랩 = 50m |
| 런지 | 덤벨 양옆(파머스 자세), 매 걸음 상단에서 발 모으고 완전 신전, 구간 라인 두 발 모두 통과 | 샌드백 어깨, 앞발이 라인 통과 |
| 쉬는 파트너 | 눕기·앉기·무릎 꿇기 금지(1차 경고, 2차 +20초), 목표량 완료 전 다음 동작으로 먼저 이동 금지 | 서서 대기 |
| 혼자 진입·퇴장 | 경고 없이 +2분 | 함께 진입·퇴장 |
| 러닝 간격 6m 이탈 | 1차 경고, 3회 누적 시 순위 제외(OOC) | 1회당 +1분, 3회 초과 시 OOC |
| 일반 동작 위반 | 2차부터 +20초 | 2차부터 +15초 |
| 월볼 공중 캐치 | 룰북에 "파트너가 공중에서 잡아 다음 스쿼트로 연결" 가능 문구 있음 → 해석 애매, '확인 필요'로만 표현 | 플라잉 트랜지션 노렙 |

- 확정적으로 말하면 안 되는 것: 월볼 공중 캐치(애매), 썰매 무게에 썰매 자체 무게가 포함되는지(룰북 미기재)
- 영상 마지막에 작게 "참가자가 만든 비공식 요약 · 최종 해석은 조직위·현장 심판" 표기
