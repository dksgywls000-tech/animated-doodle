# 직접 만든 음성으로 교체하기

이 폴더에 `scene01.mp3` ~ `scene10.mp3`(wav, m4a도 가능)를 넣고 `./render.sh`를 다시 실행하면 됩니다.

- 파일이 있는 씬은 그 파일을 쓰고, 없는 씬은 TTS로 생성합니다(일부만 교체해도 됩니다).
- 앞뒤 무음은 자동으로 잘라내고 음량도 맞춥니다.
- 씬 길이(음성 + 0.25초), 자막, 효과음, 애니메이션 타이밍이 새 길이에 맞춰 자동으로 다시 계산됩니다.
- 직접 넣은 파일은 속도를 바꾸지 않습니다. 총 길이가 28–34초를 벗어나면 경고만 출력합니다.
