# 무료(Spark) 요금제로 올리기 — 카드 등록 없음, 설치 없음

웹 브라우저 클릭만으로 끝납니다. 약 20분.

준비물: 구글 계정, Netlify 계정, 받은 파일 3개
- `netlify-upload-free.zip` (화면 폴더)
- `firestore-rules.txt` (보안 규칙)
- `명단_업로드용.csv` (명단)

---

## 1. Firebase 프로젝트 만들기

1. https://console.firebase.google.com → **[프로젝트 만들기]**
2. 이름 `fieldday-2026` → 계속 → "Google 애널리틱스" **끄기** → 프로젝트 만들기
   - 요금제는 그대로 **Spark(무료)**. 업그레이드하지 마세요.

## 2. 로그인 방식 켜기 (익명)

1. 왼쪽 메뉴 **[빌드] → [Authentication] → [시작하기]**
2. **[로그인 방법]** 탭 → **[익명]** 클릭 → **사용 설정** 켜기 → **[저장]**

> 참가자가 보는 화면은 "이름+사번"입니다. 익명 로그인은 기기를 구분하는 용도로만 쓰입니다.

## 3. 데이터베이스 만들기

1. 왼쪽 메뉴 **[빌드] → [Firestore Database] → [데이터베이스 만들기]**
2. 위치: **asia-northeast3 (서울)** → **프로덕션 모드** → 만들기

## 4. 보안 규칙 붙여 넣기 ⚠️ 꼭 해야 함

1. Firestore 화면 위쪽 **[규칙]** 탭
2. 안에 있는 글자를 **전부 지우고**, `firestore-rules.txt` 내용을 **전부 복사해서 붙여 넣기**
3. **[게시]** 클릭

## 5. 웹 앱 연결 정보 복사

1. 왼쪽 위 ⚙️ → **[프로젝트 설정]** → 아래 "내 앱"에서 **`</>`** 아이콘
2. 앱 이름 `web` → [앱 등록]
3. 나오는 값 중 4개를 메모장에 복사
   ```
   apiKey: "AIza....",
   authDomain: "fieldday-2026.firebaseapp.com",
   projectId: "fieldday-2026",
   appId: "1:1234....",
   ```

## 6. 화면 올리기 (Netlify)

1. `netlify-upload-free.zip` 압축 풀기 → `netlify` 폴더 안 **`firebase-config.js`**를 메모장으로 열기
2. `"여기에 ... 붙여넣기"` 4군데를 5단계 값으로 바꾸고 저장
3. https://app.netlify.com/drop → **`netlify` 폴더를 통째로 끌어다 놓기**
4. 나온 주소(예: `https://abc123.netlify.app`)가 **QR로 만들 주소**
   - 주소 이름 바꾸기: Site configuration → Change site name

## 7. 첫 설정 + 명단

1. **`내주소/setup`** 접속 (예: `https://abc123.netlify.app/setup`)
2. 총괄할 분의 **이름·사번·조를 명단과 똑같이** 입력 → [설정하기] → [앱으로 들어가기]
   - ⚠️ 이 화면은 **처음 한 사람만** 쓸 수 있습니다. 주소를 올린 직후 바로 하세요.
3. 아래 **[관리자 화면] → [명단·권한] → [CSV 파일 선택]** → `명단_업로드용.csv`
4. "추가 371 · 오류 0" 확인 → (확인 체크가 나오면 체크) → **[명단 반영]**

**끝!** 주소로 QR을 만들어 그룹장님 이름·사번으로 입장해 보세요.

## 리허설 후

- **한 번에 전부 지우기(행사 시작 전):** 관리자 화면 → 명단·권한 → **전체 초기화…** → 지울 항목(점수·행운권·스크래치 쿠폰·채팅·도움 요청) 확인 → `초기화` 입력 + 비밀번호
  - 명단·권한·공지·일정·조장 지정·쿠폰 당첨 제외 명단은 그대로입니다.

- 테스트로 준 점수: **관리자 화면 → 점수 기록 → 취소** (비밀번호 1234)
- 행운권 다시 섞기: **관리자 화면 → 명단·권한 → 행운권 초기화…** (`초기화` 입력 + 비밀번호)
- 쿠폰 기록 지우기: **관리자 화면 → 쿠폰 → 쿠폰 초기화…** (`초기화` 입력 + 비밀번호)
- 취소 비밀번호 바꾸기: **명단·권한 → 점수 취소 비밀번호 변경**
- 현장에서 명단에 없는 사람: **관리자 화면 → 체크인 → 인원 추가**

## 조장 체크인 현황

- 관리자 화면 → **체크인** → "조장" 칸에 이름(동명이인은 `홍길동 3조`)을 넣고 **[조장으로 지정]**
- 조장은 내 패스 화면에서 **자기 조원의 입장 여부**만 봅니다(행운권 번호·사번·다른 조는 볼 수 없음). [새로고침]을 눌러야 갱신됩니다.

## 스크래치 쿠폰(텀블러)

1. 행사 중간에 **관리자 화면 → 쿠폰** → 경품 이름(기본 `텀블러`)과 **당첨 개수** 입력 → **[쿠폰 배포] → [배포]**
2. 그 순간 **입장해 있는 모든 사람(운영진 포함)** 메인 화면에 쿠폰이 열립니다. 당첨자는 배포 순간 무작위로 정해집니다.
   - **당첨 제외 명단**(예: 조장): 쿠폰 탭 아래 칸에 이름을 넣어 두면, 그 사람도 쿠폰을 받아 긁지만 **항상 꽝**입니다. 참가자 화면에는 제외 사실이 표시되지 않습니다. 배포 **전에** 넣어 두세요.
3. 참가자가 쿠폰을 누르면 크게 열리고, 은박을 긁으면 당첨자는 **"스페셜 선물 당첨!"** + 효과음 + 무지개 효과
4. 당첨자가 부스에서 화면을 보여 주면 **쿠폰 탭의 당첨자 목록 → [수령 처리]**
5. 끝나면 **[쿠폰 마감]**. 다시 배포하면 새 쿠폰이 열립니다(배포 후 입장한 사람은 그 회차 대상이 아님)
6. 리허설 후: 쿠폰 탭 맨 아래 **[쿠폰 초기화…]** (`초기화` 입력 + 비밀번호) → 배포·당첨·긁은 기록 삭제, 모두 '잠김'으로. 당첨 제외 명단은 유지

> 배포 때 명단 전체와 입장 기록을 한 번 읽고(약 740건) 대상자 수만큼 씁니다(약 370건). 무료 한도 안에서 충분합니다.

## 무료 요금제라서 알아둘 점

| 항목 | 내용 |
|---|---|
| 하루 사용량 | 읽기 5만 건·쓰기 2만 건. 앱을 최대한 아끼도록 만들었습니다(공지·일정을 문서 하나로, 채팅은 채팅 화면에서만 실시간). **넘으면 그날 오후 4시(한국시간)까지 앱이 멈춥니다.** Firebase 콘솔 → 사용량에서 확인 가능 |
| 체크인 탭 | 열 때마다 명단 전체(약 740건)를 읽습니다. 행사 중에는 자주 열지 마세요(점수판의 요약은 적게 읽음) |
| 로그인 시도 제한 | 기기별로만 막습니다(서버가 없어 완전한 제한은 아님). 이름+사번 입장은 간편 확인이며 강한 본인 인증이 아닙니다 |
| 동시 입장 | 같은 순간에 수십 명이 처음 입장하면 행운권 번호 순서 다툼 때문에 몇 초~수십 초 걸릴 수 있습니다. 번호 중복·빈 번호는 규칙이 막습니다 |
| 다른 조 채팅 열람 | 관리자도 불가(자기 조 방만) |
| 사번 | owner만 볼 수 있습니다 |

사용량이 걱정되면 Blaze(종량제)로 바꾸고 `FIREBASE_NETLIFY_GUIDE.md`의 서버 함수 버전을 쓰면 됩니다.
