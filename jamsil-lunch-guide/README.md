# 주말 점심 소개팅 가이드

잠실(롯데월드몰·송리단길) 토요일 점심 소개팅 후보 10곳을 넘겨 보는 단일 페이지 앱입니다. `index.html`을 브라우저로 열면 바로 동작합니다.

## 보기
- **슬라이드**: 스와이프·마우스 끌기·가로 휠·←/→ 키·점 내비게이션·자동 넘김(4초, 마우스 올리면 일시정지). 옆에 현재 위치를 표시하는 미니 지도.
- **목록**: 카드 그리드. 누르면 해당 슬라이드로 이동.
- **지도**: 석촌호수·역·롯데월드몰·송리단길 개략도. 핀을 누르면 옆 패널에 정보 표시.

## 인터랙션
- 지역·음식 종류 필터, 찜하기(하트·카드 더블탭·F 키), 찜만 보기
- 비교에 담기(최대 3곳, C 키) → 나란히 비교 창
- 골라줘(R 키): 슬라이드가 감속하며 돌다가 한 곳에 멈춤
- 단축키: 1/2/3 보기 전환, Space 자동 넘김
- 카드별 소개팅 체크리스트(토요일 영업, 카카오 별점 3.8+, 네이버 방문자 리뷰 100+, '대화하기 좋아요', 2인 5–10만원, 예약·대기). 체크·찜·보기 설정은 브라우저에 저장.
- 네이버 지도·카카오맵 바로가기, 전화는 네이버 장소 페이지의 전화 버튼으로 연결.

별점·리뷰 수는 앱에 넣지 않았습니다. 네이버·카카오가 자동 수집을 막고 있어 카드의 지도 버튼으로 확인합니다.
