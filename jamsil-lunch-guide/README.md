# 주말 점심 소개팅 가이드

잠실(롯데월드몰·송리단길·석촌호수) 토요일 점심 소개팅 식당을 정해진 기준표로 점수화하는 단일 페이지 앱입니다. `index.html`을 브라우저로 열면 바로 동작합니다(입력값은 브라우저에 저장).

- 네이버 지도·카카오맵 바로가기, 전화 걸기(번호 입력 시 `tel:` 링크, 미입력 시 네이버 지도 장소 페이지로 연결)
- 판정 기준(100점): 맛·만족도 30(카카오 별점), 검증된 인기 20(네이버 방문자 리뷰·카카오 후기 수), 대화 환경 20, 2인 객단가 15, 토요일 운영 편의 15
- 탈락 조건: 토요일 점심 미영업, 카카오 별점 3.8 미만, 리뷰 표본 부족
- 별점·리뷰 수는 추정하지 않고, 지도 앱에서 확인한 값을 "근거 입력"으로 넣으면 확인일과 함께 저장됩니다. 필수 근거가 비면 "판정 보류"입니다.
