# 솔로 할로윈 — 웹 소개팅 사이트

10/30(금) 이태원 솔로파티용 모바일 사이트. 파일 하나(`index.html`)로 동작합니다.
포스터의 톤(성당 스테인드글라스 · 앰버 빛 · 흰 글씨에 크림슨 외곽선 · 둥근 한글 서체)을 그대로 가져왔고, 행사 일정은 사이트에 넣지 않았습니다.

## 1. 참가자 흐름

```
이름 + 생년월일 로그인
   │  (처음 로그인한 사람만)
   ├─▶ 🕯️ 촛불 탭 → 힉스필드 인트로 영상 + 환영 문구 → "솔로 할로윈" 타이틀
   ├─▶ 캐릭터 대화 (게임처럼 탭해서 넘기기)
   │     잭: 파티 소개 → 닉네임·아바타·코스튬 정하기
   │     잭: 라운드 시계 → 피피: 사탕·밀담방·편지 → 루시안: 베스트 드레서 → 부: 운명의 실 → 헤이즐: 방들
   └─▶ 메인 (다음 로그인부터는 바로 여기로)
```

- 실명은 로그인 확인에만 쓰입니다. 화면에는 **닉네임만** 나옵니다.
- 인트로는 서버 프로필에 `seen` 표시가 남아서, 다른 기기로 다시 로그인해도 반복되지 않습니다. (명찰 수정 › "인트로 다시 보기"로 재생할 수 있습니다.)

### 매칭 규칙
1. 이성을 최대 3명 고릅니다. 순위는 없습니다.
2. **서로가 서로를 고르면 매칭**입니다. 겹치는 사람이 있어도 우선순위를 따지지 않고, 서로 고른 모든 쌍이 매칭됩니다.
3. 관리자가 **"종료"**를 누르면 선택이 잠기고 결과가 서버에 고정됩니다. **30분 뒤**(관리자 화면에서 변경 가능) 모든 폰에 자동 공개됩니다. **"발표"**를 누르면 바로 공개됩니다.
4. 공개 화면에는 **나를 고른 사람 수(받은 표)**와 **매칭된 상대 전원**이 나옵니다.

## 3. 캐릭터 설계

모두 SVG와 CSS로 그려서 이미지 파일이 필요 없습니다. 말하는 동안에는 입이 움직이고, 눈은 몇 초마다 깜빡입니다.

| 캐릭터 | 콘셉트 | 등장 동작 | 평소 동작 | 소개하는 기능 |
|---|---|---|---|---|
| 🎃 **잭** | 마녀 모자를 빌려 쓴 호박 MC. 들뜨고 시끄러움 (포스터의 모자 쓴 호박) | 위에서 떨어져 찌그러졌다가 튀어 오름 | 통통 바운스 · 눈과 입의 불빛 깜빡임 · 모자 까딱 | 파티 소개, 닉네임, 로비, 빙고 |
| 🦇 **피피** | 편지를 든 박쥐 우체부. "삐익!" | 오른쪽 위에서 지그재그로 날아옴 | 빠른 날갯짓 + 위아래 호버 | 사탕·편지 배달, 도감 |
| 🧛 **루시안** | 저택 주인이자 호스트 뱀파이어. 느리고 우아한 말투 | 박쥐 떼가 흩어지면서 망토가 회전하며 나타남 | 망토 펄럭임 · 말할 때 한쪽 눈썹 올림 | 베스트 드레서, 대화 카드, 선물 |
| 👻 **부** | 작은 모자를 쓴 수줍은 유령. 운명의 실 담당 (포스터의 유령) | 흐릿하게 깜빡이며 서서히 나타남 | 둥실둥실 흔들림 · 꼬리 살랑 · 수줍으면 손으로 얼굴 가림 | 운명의 실, 결과 발표 |
| 🧙 **헤이즐** | 빗자루 탄 점술 마녀. 장난스러움 | 왼쪽 위에서 빗자루로 급강하 | 기울어진 호버 · 빗자루 끝 반짝이 | 방들, 타로, 몬스터 테스트 |

**대사 효과음:** 자막이 한 글자씩 찍힐 때 캐릭터마다 다른 목소리 효과음이 납니다. 파일 없이 브라우저에서 합성합니다. 잭은 통통 튀는 중간 톤, 피피는 높은 '삐익', 루시안은 낮고 느린 톤, 부는 떨리는 톤, 헤이즐은 장난스럽게 내려가는 톤입니다. 대화 화면 오른쪽 위 🔊 버튼으로 끌 수 있습니다.

화면별 연출: 인트로 박쥐 떼, 타이틀 글리치, 관이 덜컹거리다 열림, 붉은 실이 그려지고 하트가 터짐, 단상이 솟고 왕관이 떨어짐, 타로 카드 3D 뒤집기, 대화 카드 날려 넘기기, 빙고 호박 도장, 이모지 컨페티.

## 4. 행사 전 준비 (운영진)

### ① 실시간 DB 연결 — 필수
투표와 매칭은 모든 참가자 폰이 같은 데이터를 봐야 하므로 **Firebase Realtime Database**를 씁니다. 무료 플랜으로 충분합니다.

1. [Firebase 콘솔](https://console.firebase.google.com) → 프로젝트 만들기 → *Realtime Database* → 데이터베이스 만들기 (위치: 싱가포르 `asia-southeast1`) → **테스트 모드**
2. 생성된 주소(예: `https://solo-halloween-default-rtdb.asia-southeast1.firebasedatabase.app`)를 `index.html`의 `CONFIG.DB_URL`에 넣습니다.
3. `CONFIG.ADMIN_PIN`을 바꿉니다. (기본값 `1031`)

`DB_URL`이 비어 있으면 **로컬 데모 모드**로 동작합니다. 데이터가 그 기기에만 저장되므로 리허설용으로만 쓰세요.

### ② 참가자 명단 넣기
관리자 화면 › **📜 명단 만들기**에 한 줄에 한 명씩 붙여넣습니다.
```
홍길동 950315 남
김영희 1997.08.22 여
```
- **서버 명단으로 올리기**: 파일 수정 없이 바로 반영됩니다 (권장).
- 또는 **변환하기** 결과를 `index.html`의 `ROSTER` 배열(`/*ROSTER_START*/`~`/*ROSTER_END*/`)에 붙여넣습니다.

실명과 생년월일은 해시로만 저장되고 원본은 어디에도 올라가지 않습니다.
지금 들어 있는 `테스트일 950101`(남) ~ `테스트육 000606`(여) 6명은 **데모 계정이니 행사 전에 교체**하세요.

### ③ 배포
GitHub Pages 같은 HTTPS 정적 호스팅에 `index.html`만 올리면 됩니다. QR 코드로 링크를 나눠주세요.

## 5-1. 로테이션 라운드 (10라운드)

시간은 현장 상황에 따라 달라지므로 **운영진이 관리자 화면에서 라운드를 시작하는 순간** 모든 참가자 폰의 시계가 흐르기 시작합니다. 화면에 실제 시각은 나오지 않습니다.

- **로비 맨 위의 Midnight Clock:** 남은 시간 링, `ROUND IV / X`, 촛불 10개(지난 라운드는 꺼지고 지금 라운드만 타오름)가 보입니다. 마지막 1분이 되면 숫자가 붉게 뛰고, 이동 시간에는 청록색으로 바뀝니다.
- **상단 미니 타이머:** 어느 탭에 있든 `IV · 07:57`과 금빛 진행선이 보입니다.
- **라운드가 시작될 때:** 전원의 폰에 "ROUND IV · 피의 맛" 타이틀 카드가 뜨고 진동이 울립니다.
- **대화 시간이 끝날 때:** 🔔 종이 울리고 이동 시간이 자동으로 흐릅니다. 다음 라운드는 이동이 끝난 걸 보고 운영진이 직접 시작합니다.
- **★ 기억 노트:** 이동 시간마다 "방금 테이블에서 기억할 영혼"에 ★를 남깁니다. 본인만 볼 수 있고, 운명의 실 목록 맨 위에 `★ III`처럼 몇 라운드에서 만났는지와 함께 나옵니다. 40명 가까이 만나도 헷갈리지 않게 하려는 장치입니다.

|---|---|---|---|
| I | 가면 소개 *The Masks* | 잭 | 건배하고 서로의 닉네임 외우기 |
| II | 밤의 취향 *Creatures of the Night* | 피피 | 가장 밤형 인간 뽑기 |
| III | 공포 취향 *What Scares You* | 헤이즐 | 가장 겁 많은 영혼 지목 |
| IV | 피의 맛 *Blood & Bite* | 루시안 | 잔 채워주며 건배사 |
| V | 몬스터 유형 *Monster Type* | 헤이즐 | 같은 몬스터 유형 찾기 |
| ☕ | 숨 고르기 3분 | 피피 | 물 한 잔 · 빙고 · ★ 정리 |

| 🕯 | 자유 시간 | 부 | ★ 기억해둔 영혼 찾아가기 |

라운드마다 질문 3개와 미션 1개가 로비에 나옵니다. 내용은 `index.html`의 `ROUNDS` 배열에서 고칠 수 있습니다.

**관리자 › ⏱ 라운드 진행:** `▶ ROUND N 시작` · `⏸ 일시정지/재개` · `+1분 / −1분` · `⏭ 지금 종 울리기` · `☕ 숨 고르기 3분` · `🕯 자유 시간` · `■ 대기 화면`. 대화와 이동 시간(기본 8분/2분)은 관리자 화면에서 바꿀 수 있고, 라운드 번호는 − / + 로 보정합니다.

**당일 순서 예시:** 20:30 ROUND I 시작 → … → V → ☕ 숨 고르기 → VI … X → (정리) → 🕯 자유 시간 + 운명의 실 "열림" → 22:50 운명의 실 "마감" → 23:10 베스트 드레서 "발표" → 23:20~ 운명의 실 "종료"(30분 뒤 자동 공개).

> 운영진용 **가이드북**은 **`guidebook.html`**(실제 화면 캡처와 번호 설명, `guide-img/` 폴더 필요)이고, 한 장 요약은 **`guide.html`** 입니다. 관리자 화면 위쪽의 📖 버튼으로도 열 수 있고, A4 가로 한 장으로 인쇄됩니다.

## 5-2. 🚪 비밀의 방 이벤트 (파티 중간)

1. 관리자 › **🚪 비밀의 방 이벤트** › `🎬 비밀의 방 시작`을 누르면 모든 참가자 폰이 이벤트 화면으로 바뀝니다(진동).
2. 문을 누르면 **루시안이 말하는 영상**이 나옵니다. 힉스필드에서 사이트 캐릭터 5명의 레퍼런스 이미지를 만들고, Seedance 2.5로 한국어 대사와 효과음까지 생성했습니다. 대사: “잘들 즐기고 있나, 영혼들이여? 지금부터 단 한 명을 지목하라…”
3. 영상 시간(기본 17초)이 지나면 **3분 지목**이 시작됩니다. 이성 한 명만 고를 수 있고, 시간 안에는 바꿀 수 있습니다.
4. 시간이 끝나면 **서로 지목한 쌍**에 랜덤 번호가 붙습니다. 이벤트 id를 씨앗으로 섞기 때문에 모든 폰에서 같은 번호가 나오고, 관리자 화면이 결과를 서버에 고정합니다. 1번부터 안쪽 자리에 앉습니다.
5. 운영진은 `📺 발표 화면`으로 번호표를 크게 띄우거나 `번호표 복사`로 공유합니다. 이어진 쌍에게는 💬 밀담방이 열리고, 이벤트를 닫아도 유지됩니다.

영상 파일은 `CONFIG.SECRET_VIDEO`에 있습니다(`secret.mp4` → 힉스필드 CDN 순서로 재생). 행사용으로는 영상을 받아 `secret.mp4`로 함께 올리는 것을 권장합니다.

## 7. 알아둘 점
- 테스트 모드의 Firebase는 주소를 아는 사람이면 데이터를 읽고 쓸 수 있습니다. 하룻밤 행사용으로는 충분하지만, **행사가 끝나면 DB를 삭제**하세요.
- "익명"은 화면에서만 익명입니다. DB를 직접 열어보면 보낸 사람을 알 수 있습니다. 밀담방 대화도 DB에 남습니다.
- 편지는 익명이지만 도착하면 서로의 인스타가 공유되므로, 인스타를 보면 누가 보냈는지 짐작할 수 있습니다(의도된 규칙).
- Firebase 연결 시 **실시간 스트림**으로 바뀐 부분만 받아옵니다. 그래서 채팅이 바로 반영되고, 무료 플랜의 데이터 사용량 안에서 운영됩니다.
- 로그인 해시는 이름과 생일 조합이라 마음먹고 대입해 보면 풀릴 수 있습니다. 실명이 화면에 노출되지 않게 하는 정도의 보호입니다.
