관리자 화면: 로고 5번 연속 탭 또는 주소 뒤 #admin → PIN
참가자 로그인: 이름 + 생년월일(6자리 또는 8자리) → 이후 닉네임으로만 활동

⏱ 라운드 진행 관리자 › 라운드 진행

  1. 테이블이 준비되면 ▶ ROUND N 시작을 누릅니다.
  2. 모든 폰에 라운드 타이틀이 뜨고 시계가 흐릅니다 (대화 8분).
  3. 대화 시간이 끝나면 🔔 종 + 진동, 이동 2분이 자동으로 흐릅니다.
  4. 이동이 끝난 걸 확인하고 다음 라운드를 시작합니다.
I~V→☕ 숨 고르기 3분→VI~X→정리→🕯 자유 시간

조절: ⏸ 일시정지 ±1분 ⏭ 지금 종 울리기. 라운드 번호는 −/+ 로 보정합니다. 관리자 화면을 보는 동안에는 타이틀 카드가 뜨지 않습니다.

★ 기억 노트: 이동 시간마다 참가자가 방금 만난 사람에게 ★를 표시합니다. 본인만 보이고, 운명의 실 목록 맨 위에 나옵니다.

🍬 사탕 · 💬 밀담방 캐릭터: 피피

  • 사탕은 보낸 사람의 닉네임이 공개됩니다.
  • 받은 사람은 🍬 돌려주기를 누를 수 있습니다.
  • 서로 주고받으면 둘만의 밀담방(1:1 채팅)이 열립니다.
  • 1인당 5개를 먼저 보낼 수 있고, 돌려주기는 개수 제한이 없습니다.
  • 운명의 실로 매칭된 상대와도 밀담방이 열립니다.

🦇 편지 캐릭터: 피피

  • 편지는 익명이고, 정해진 문구 8개 중에서만 고릅니다(악성 메시지 방지).
  • 도착하는 순간 서로의 인스타 아이디가 공유됩니다. 받은 사람은 보낸 이의 인스타를, 보낸 사람은 받은 사람의 인스타를 봅니다.
  • 1인당 5통까지 보낼 수 있습니다.
  • 인스타를 등록하지 않으면 상대 화면에 "인스타 미등록"으로 나옵니다. 입장할 때 등록을 권해 주세요.

🩸 운명의 실 (최종 선택) 캐릭터: 부

  • 이성을 최대 3명 고릅니다. 순위는 없습니다.
  • 서로 고르면 매칭입니다. 한 사람이 여러 명과 매칭될 수 있습니다.
  • 공개되면 각자 받은 표 수와 매칭된 상대(인스타, 밀담방, 선물 티켓)를 봅니다.
대기→열림→마감 (22:50)→종료→ 30분 뒤 자동발표

종료를 누르면 선택이 잠기고, 모든 폰에 공개 카운트다운이 뜹니다. 공개까지의 시간(기본 30분)은 관리자 화면에서 바꿀 수 있습니다. 발표를 누르면 바로 공개됩니다.

👑 베스트 드레서 캐릭터: 루시안

  • 남녀 각 1표씩, 본인은 뽑을 수 없습니다. 마감 전까지는 바꿀 수 있습니다.
  • 단계: 대기 → 열림 → 마감 → 발표(시상대 애니메이션).
  • 득표 순위는 관리자 화면에서 실시간으로 볼 수 있습니다.

🧰 그 밖의 도구

  • 🚪 비밀의 방: 🎬 시작 → 루시안 영상 → 3분 안에 한 명 지목 → 서로 지목한 쌍에 랜덤 번호(1번부터 안쪽 자리) → 📺 발표 화면.
  • 🎡 경품 룰렛: 전체, 남, 여, 미매칭 중 대상을 골라 추첨합니다.
  • 🍷 테이블 나누기: 남녀를 섞어 N개 테이블로 나눕니다(참고용).
  • 📸 인스타 태그: 태그에 동의한 사람의 @아이디를 한 번에 복사합니다.
  • 📜 명단 만들기: "이름 생년월일 성별"을 붙여넣고 서버에 올립니다.
  • 🧹 초기화: 투표, 운명의 실, 전체 데이터를 지웁니다.

✅ 행사 전 체크리스트

  • index.html의 DB_URL(Firebase)과 ADMIN_PIN을 바꿨다
  • 실제 명단을 서버에 올리고, 테스트 계정이 로그인되지 않는 것을 확인했다
  • index.html, intro.mp4, guide.html, guidebook.html, guide-img 폴더를 넷리파이에 올렸다
  • 폰 2대로 사탕 → 돌려주기 → 밀담방, 라운드 시작/종을 리허설했다
  • 입장 QR 코드를 출력했다

🆘 이럴 땐

  • 로그인이 안 됨: 명단의 이름과 생년월일 표기를 확인합니다(공백은 무시됩니다).
  • 인트로를 다시 보고 싶음: 닉네임 → 🎬 인트로 다시 보기.
  • 시계가 안 맞음: 폰의 자동 시간 설정을 켜게 합니다.
  • 소리가 안 남: 아이폰 무음 스위치를 확인하고, 대화 화면 🔊 버튼을 켭니다.
  • 행사가 끝나면: Firebase 데이터를 삭제합니다(채팅 포함).

🔒 개인정보 · 데이터

  • 실명과 생년월일은 해시로만 저장되고, 화면에는 닉네임만 보입니다.
  • "익명"은 참가자 화면에서만 익명입니다. 운영 DB에는 보낸 사람이 기록됩니다.
  • 밀담방 대화도 DB에 남습니다. 행사가 끝나면 Firebase 데이터를 삭제해 주세요.
